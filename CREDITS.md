# Credits

Crusader Kings III DNA Studio is published at [BIoodWork/CK3-DNA-Studio](https://github.com/BIoodWork/CK3-DNA-Studio).

## Community references

- **figment** — the original CK3 Cheat Engine table supplied at the start of this project was a starting point for investigating character selection and DNA memory access.
- **[grmk / CK3-DNA-Manager-Qt](https://github.com/grmk/CK3-DNA-Manager-Qt)** — inspiration for DNA-library workflows and the reference for the supported `ck3-dna-manager-qt` JSON import format. Studio's importer reads that export format into its own library model.
- **[Welshtokki / CK3_DNA_Manager](https://github.com/Welshtokki/CK3_DNA_Manager)** — an earlier CK3 DNA manager acknowledged as inspiration for the character-library and DNA-editing workflow.

These acknowledgements do not imply affiliation, endorsement or maintenance of Studio by those projects.
