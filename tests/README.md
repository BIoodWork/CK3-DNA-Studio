# Regression tests

From the project directory, run `node scripts/test.js` (or `npm test`). The runner uses the production files beneath this project's `src` and `backend/python`; it does not exercise a copied application or a previously built executable.

`node scripts/test.js --node` runs the Node tests. `node scripts/test.js --python` runs Python unittest discovery. The complete command runs both groups and returns a failure status if either group fails. No tests are silently skipped, and no dependencies are installed.

Node must support `node --test` and `--test-concurrency=1` (the supported project runtime is Node 22). Python requires version 3.10 or newer and the project's existing Pillow dependency. The runner tries `CK3_CONVERTER_PYTHON` when set; otherwise it tries `python`, `py -3`, then Windows Python installations under `%LOCALAPPDATA%/Python/pythoncore-*`. Set `CK3_CONVERTER_PYTHON` to a Python executable path to select an environment explicitly.

The current conversion integration tests read installed CK3, EPE and AGOT gene definitions and portrait palettes. They target the verified schema counts of 104, 130 and 187 ordinary genes, respectively. Install those game/mod versions or configure `CK3_GENES_DIR`, `CK3_EPE_GENES_DIR` and `CK3_AGOT_GENES_DIR` to their `common/genes` directories. These tests intentionally fail if the required definitions are unavailable or differ from the verified schema. They read installed assets; they do not modify them. The compatibility tests create their own isolated game/mod fixtures, and the live-game tests use simulated memory without opening the running game.

Temporary fixtures are created beneath `tests/node/tests` and `tests/python/tmp` and removed by their tests. The runner creates these parent directories when necessary. The build's application file list excludes this test directory.

## Data fixtures

`fixtures/live_dna.bin` retains its historical fixture filename, but contains **synthetic** EPE DNA generated with seed `20261030`, not DNA captured from a user's character. It contains 130 four-byte gene slots (520 bytes) and no names or game-save data. `fixtures/generate_synthetic_dna.py` regenerates it from the installed EPE schema. Its SHA-256 is `6b088e62578df006212bb3d7159bdfd40346a8c84b742449574d6f8b5982cee8`; its Murmur3 test value is `0xda9beb08`.

`fixtures/agot_sample.txt` is wholly synthetic named AGOT DNA generated with seed `20261101`. It has the 187 ordinary genes from the installed schema plus the supported text-only `hairstyles` gene. Its `synthetic_agot_0` / `portrait_info` wrapper uses `id=0` and contains no saved character, personal name, portrait or user library. Its SHA-256 is `af8dccabcb1fd9ee9c3ee78685461a784d30f97c240e55098d8765b9ad142f6e`. The generator chooses valid templates and byte strengths from seeded randomness; it reads only installed gene definitions. The tests independently construct unsupported/future syntax when testing read-only preservation.

Run `python tests/fixtures/generate_synthetic_dna.py` with the verified installed EPE/AGOT definitions to regenerate both fixtures. Reproduction tests compare the generated bytes/text with the checked-in fixtures. Test process memory is simulated; its example selected character is named `Synthetic Hero`. Fixtures are development inputs and are excluded from application packaging.

The backend retains only the modules reachable from its current bridge actions. Unused historical field-order/token tables extracted from an unidentified legacy converter bundle and their unused legacy conversion services have been removed. Current conversion and editing load definitions from the user's game/mod installation; no historical bundle tables are shipped. The optional NumPy dependency is excluded from the frozen backend because all active image handling uses Pillow and all numeric palette work uses Python's standard library.
