# Release privacy

The source repository and installer are built from an explicit file allowlist.
They do not contain the developer's library, portraits, preferences, installation-path settings, saved-game data or local build logs.

A new user profile starts with an empty library and English selected. Existing users retain their own local library and explicit language preference. Uninstalling or updating the application does not import the developer's data.

All DNA processing is local. Gene definitions and portrait palettes are read from the user's own installed game and mods. The application has no account, telemetry, cloud backend or automatic update service.

Library/profile exports intentionally include the names, notes, DNA and optional portraits selected by their owner. Review an export before sharing it.

The public author identity is BIoodWork. Third-party copyright holders and their license notices are listed separately.
